## ロゴを使えないイベントの告知画像

使用許可のあるロゴ・画像がないときは、生成AIを使わず `tools/events/make_event_image.py`（HTML/CSS → playwright で 1600×900）で、事実（催し名・日付・時間・会場）と自社作品の公式素材だけの画像を作る。主催のロゴは使わない。仕様の例は `tools/events/specs/example.json`。
