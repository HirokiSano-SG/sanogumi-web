第1条本規約の適用

  1. 本規約は、本会への出展の申し込みから、本会の終了後の後片付け・データの取り扱いまで、主催者と出展者の間の一切の関係に適用されます。
  2. 主催者が本会について別途お知らせする案内・注意事項（メール、公式X、主催者のお知らせページ等）も、本規約の一部とします。
  3. 出展者は、会場施設の規則（第14条）もあわせて守るものとします。

第3条出展の形

出展は、次の3つの形から選んでいただけます。複数の形を組み合わせることもできます。

  1. 会場で出展：当日会場にお越しいただき、ご自身で展示・説明をしていただきます。
  2. 代理展示：出展者からゲームのビルドをお預かりし、主催者が会場のPCにインストールして展示します。本会の終了後、主催者がアンインストールします（第10条）。
  3. リモート参加：意見交流会とLTに、オンラインでご参加いただきます（第11条）。
  • 受け入れる数は、会場の広さと電源の容量に応じて、審査の中で主催者が調整します。

第4条出展の資格・対象作品

  1. 出展者は、出展作品の制作に主体的に関わっている個人、サークル、チームまたは法人とします。出展者の区分は、個人・法人・その他の団体を問いません。
  2. 出展作品は、次のすべてを満たすものとします。
    1. Windows 向けのゲームのビルドであること。ただし、会場で出展する方がご自身で機材を持ち込む場合に限り、ほかのOSやスマートフォン向けの作品もご相談いただけます。
    2. 当日、会場で試遊できる状態であること（体験版・開発中のものでも構いません）。
    3. 出展者が必要な知的財産権を持っているか、正当な権利者から許諾を得ていること（二次創作は第6条のとおりとします）。
    4. 第5条の表現の条件を満たすこと。
    5. 出展者自身が制作した作品であること（次項）。
  3. 展示できるのは、出展者自身が企画・制作した作品に限ります。ゲームエンジンや開発ツールに付属するサンプル・デモ、テンプレート、購入または入手したアセット・素材を、ほぼそのまま（出展者自身による実質的な制作や改変を加えずに）ビルドしたものは、出展作品として認められません。
  4. 前項は、正規にライセンスを受けたアセット・素材・ツールを、出展者自身の作品の一部として、ライセンスの条件に従って使うことを妨げるものではありません。
  5. 前2項に当てはまるかどうかは、第7条の審査で主催者が判断します。主催者は、判断のために、制作の内容や使用したアセット・素材について説明を求めることがあります。
  6. 出展の代表者が未成年の場合は、事前に親権者の同意を得てください。お申し込みをもって、同意を得たものとみなします。
  7. 1つの出展者が出展できる作品数は1本以上で、本数の上限は設けません。ただし、出展者ご自身が試遊の列や試遊者の案内に対応できる範囲に限ります。

第5条表現の条件

  1. 成人向け（18歳未満の方の閲覧・プレイに適さない性的な内容）の作品、およびそれに類する作品は出展できません。
  2. 暴力、ホラー、流血などの表現を含む作品は、ブースでの掲示、または起動時の画面で、その旨の警告を表示していただくことを条件に出展できます。
    • 1台のPCに複数の作品を入れてランチャーで選ぶ形（第9条）の場合は、起動時の警告を必須とします。
    • 主催者が A4 の警告表示の見本を用意します。形式は自由で、来場者に内容が伝われば構いません。
  3. 前2項のほか、法令や公序良俗に反する内容、特定の個人・団体を誹謗中傷する内容、差別を助長する内容を含む作品は出展できません。
  4. 会場は一般の方も利用する商業施設内にあります。来場者に年少者が含まれる可能性があることに配慮した展示をお願いします。

第6条二次創作

  1. 二次創作の作品は、次のすべてを満たす場合に限り出展できます。
    1. 原作の権利者が公開しているガイドライン（利用規約・二次創作ガイドライン等）の範囲内であること。
    2. 非営利であること（有償の頒布・販売、有料の配信、寄付の募集などを行わないこと）。
  2. 前項に当てはまるかどうかの判断と、その結果についての責任は、出展者が負うものとします。
  3. 権利者から申し立てがあった場合や、主催者が必要と判断した場合は、会期中であっても展示を中止していただくことがあります。

第7条申し込みと審査

  1. 出展の申し込みは、主催者が定める方法（出展者募集ページに掲載する申し込みフォーム）で行ってください。
  2. 募集は2回に分けて行います。どちらの募集でも、第3条のすべての出展の形でお申し込みいただけます。
    募集申し込み締切審査結果のご連絡
    1次募集2026年11月1日（日）2026年11月8日までに
    2次募集2026年11月25日（締切厳守）随時
  3. 申し込み時に、次のものを必ずご提出ください。
    • 作品名
    • 紹介文
    • 画像（1枚以上）
    • 遊べるビルド、または作品の内容が分かるURL（動画のURLでも構いません）
  4. 出展は、内容を拝見したうえでご案内します。会の趣旨により、ご希望に沿えない場合がありますので、あらかじめご了承ください。
  5. 審査の基準や、ご希望に沿えなかった理由はお伝えしておりません。
  6. 審査結果は、メールでお知らせします。
  7. 出展の権利を第三者に譲ったり、転売したりすることはできません。

第8条出展料・任意のカンパ

  1. 出展料は無料です。
  2. 本会の運営費にあてるため、一口1,000円の任意のカンパを受け付けます。カンパは任意であり、カンパの有無や口数によって、審査・展示の扱いが変わることはありません。
  3. カンパは、当日会場で現金にて受け付けます。領収書をお出しします。
  4. 本会が中止となった場合は、カンパはお受け取りしません。

第9条機材と展示方法

  1. 主催者が会場で用意する機材は、次のとおりです。
    • 24インチ FHD ディスプレイ
    • Xbox または PlayStation のコントローラー（パッド）
  2. 会場で出展する方は、前項以外の機材（PC、ケーブル類、キーボード・マウス等の入力機器、ヘッドホン、スピーカー、その他の入出力機器、掲示物など）は、出展者がご用意・お持ち込みください。
  3. 申し込みが多い場合は、1台のPCに複数の作品をインストールし、ランチャーから選んで遊んでいただく形にすることがあります。この場合に使うPCは主催者が用意します。出展者は、主催者が出展作品をそのPCにインストールし、ランチャーに登録し、本会の終了後にアンインストールすることに同意するものとします。ビルドの提出と取り扱いは、第10条1項および3項から6項に準じます。
  4. 出展者は、持ち込む機材の一覧と消費電力を、2026年11月22日までに主催者へお知らせください（第14条4項）。
  5. 展示スペースの広さ、机・ディスプレイ・コントローラーの台数、配置は、応募状況を見て主催者が決めます。
  6. 出展者は、来場者が安全に試遊できるよう、配線や機材の置き方に配慮してください。

第10条代理展示

  1. 代理展示を選んだ出展者は、ビルドを共有リンクで主催者にお渡しください。期日は次のとおりです。
    • 1次募集で出展が決まった方：2026年11月22日まで
    • 2次募集の方：お申し込みと同時
    • お渡しした後のビルドの差し替えは、ご相談ください。
  2. 代理展示に使うPCは主催者が用意します。出展者は、主催者が本会で展示するために、ビルドを複製し、会場のPCにインストールし、来場者に試遊させることを許諾するものとします。
  3. 主催者は、お預かりしたビルドを本会の展示以外の目的で使用せず、第三者に渡しません。
  4. 主催者は、本会の終了後、会場のPCからビルドをアンインストールし、受け渡しに使ったデータを削除します。削除が終わったら、メールでお知らせします。
  5. 出展者は、お渡しするビルドにマルウェア等の有害なプログラムが含まれていないことを確認してください。ビルドが原因で会場の機材や第三者に損害が生じた場合は、出展者の責任とします。
  6. 動作に必要な設定・注意点（解像度、操作方法、既知の不具合など）は、ビルドと一緒にお知らせください。主催者は、当日の動作不良について、できる範囲で対応しますが、動作を保証するものではありません。

第11条リモート参加・LT

  1. リモート参加の出展者は、Google Meet で意見交流会とLTにご参加いただけます。開催前日に接続テストを行います。リモート参加に関する連絡は Discord で行います。
  2. LTは、1人5分、最大8枠です。発表を希望する方は、主催者が用意するフォームでお申し込みください。希望者が枠を超えた場合は、主催者が発表者を選びます。
  3. LTは、録画での発表もできます。録画は5分以内とし、2026年11月25日までに主催者へご提出ください。当日は主催者が会場で再生します。ご本人の声ではなく、合成音声や字幕だけの録画でも構いません。
  4. 通信環境の不具合などで、参加や発表ができなくなる場合があります。その場合でも主催者は責任を負いません。
  5. 意見交流会は出展者・関係者のみの場です。リモート参加の方も、その場で知った他の出展者の未公開情報を、本人の許可なく外部に公開しないでください（第15条）。

第12条試遊者アンケート・フィードバック

  1. 出展者が試遊者へのアンケートを使う場合は、2026年11月27日までに、アンケート（URL・QRコード等）を主催者へ共有してください。
  2. アンケートで個人情報を集める場合は、出展者が自らの責任で、利用目的の明示など法令に沿った取り扱いをしてください。
  3. 来場者の感想のフィードバックが要るか要らないかを、お申し込み時にお知らせください。希望された方には、本会の終了後2週間以内にメールでお送りします。

第13条当日の運営

  1. 出展者は、設営時間（11:00〜12:00）のうちに設営を終えてください。
  2. 一般の方の来場は16:00で終了し、一般の方には退場いただきます。16:00〜17:00の意見交流会は、出展者・関係者のみで行います。
  3. 会場の定員を超えないよう、主催者が入場を制限することがあります。
  4. 会場に入れるのは、出展者ご本人を含めて1組3名までです。これを超える場合は、事前にご相談ください。
  5. 本会の運営について、出展者は主催者および会場スタッフの指示に従ってください。
  6. 出展者は、自作のグッズやゲームを販売できます（会場への申請は不要です）。価格の設定・代金の受け渡し・購入者とのトラブルへの対応は、出展者ご自身の責任で行ってください。

第14条会場規則の遵守

本会は、枚方パートナーシップス株式会社が運営する「ビィーゴ」のレンタルスペースを主催者が借りて開催します。出展者は、ビィーゴの利用規約・注意事項（以下「会場規則」）を必ず守ってください。会場規則と本規約が異なる場合は、会場規則を優先します。会場規則に違反した場合、会場の判断で利用が止められ、本会全体が中止になるおそれがあります。

主な会場規則は次のとおりです（2026年9月29日に会場の公開ページで確認した内容です。詳しくは会場の利用規約をご確認ください）。

  1. 持ち込み禁止のもの：動物（盲導犬・介助犬を除く）、危険物（火薬類、爆発性物質その他会場が危険と判断したもの）。
  2. 飲食：会場の飲食は事前申請制です。主催者が申請した範囲を超える飲食物の持ち込みはできません。臭いの残るもの・汚れやすいもの、アルコール類、デリバリー（宅配）サービスの利用、コンロ・ホットプレート・電子レンジ等の使用、レンタルスペース（イベントルームB）の外での飲食は禁止です。本会では、主催者が飲料と軽食を申請します。これ以外の飲食物はお持ち込みいただけません。
  3. 音：大声、大音量、楽器の演奏、振動、臭いなどで、ほかの利用者に迷惑をかける行為は禁止です。会場は完全防音ではないため、試遊の音量は控えめにし、必要に応じてヘッドホンをお使いください。
  4. 電源：持ち込み機器の電気の使用は1500W（100V）までが目安です。合計の使用電力が1,000W以上になる場合は、利用日の5日前までに会場へ機器名・消費電力の一覧を申請する必要があります（申請は主催者がまとめて行います）。同じ回路の合計は1,600W以内、イベントルームの合計は6,000W以内です。延長コードは必要に応じてお持ちください。人が通る場所に配線する場合は養生してください。
  5. 掲示物：施設・設備・備品へのテープ貼り、画鋲、釘打ちは禁止です。案内看板・広告物の掲示は許可制で、決められた場所以外には置けません。掲示物はご自身の机の上に置けるスタンド等をお使いください。
  6. チラシ配布・呼び込み：会場施設の内外でのチラシ配布・客引きは禁止です。展示・呼び込みは割り当てられたスペースの中だけで行ってください。
  7. 勧誘・宗教・政治活動：営利・非営利を問わず、勧誘行為（団体加入の勧誘を含む）、宗教活動、政治活動、署名活動は禁止です。
  8. 喫煙：施設内は禁煙です（電子たばこを含む）。
  9. 搬入出：リュックやキャリーバッグなどの手荷物は、お客様用の出入口から持ち込めます。台車を使う搬入や、車を搬入口に停める搬入は、枚方ビオルネ1階裏手の搬入口と会場が指定する経路を使ってください。お客様用の出入口・エレベーター・エスカレーターは使えません。会場への事前申請（利用日の5日前まで）が必要で、申請は主催者がまとめて行います。これらを希望する出展者は、2026年11月22日までに主催者へご連絡ください。
  10. 荷物の事前送付：会場への荷物の事前送付ができます。主催者を通じて会場へ申請しますので、希望する方は2026年11月22日までに主催者へご連絡ください。申請せずに会場へ送らないでください。返送は出展者ご自身で手配してください。
  11. 原状回復・ごみ：使用後は元の状態に戻してください。ごみは原則お持ち帰りください。
  12. 施設・備品の破損：施設・設備・備品を壊したり、汚したり、なくしたりした場合、会場から実費の賠償を求められます。出展者が原因の場合は、出展者にご負担いただきます（第19条）。
  13. 利用時間：会場の予約時間より前に入室することはできません。出展者の入室は設営開始の11:00からです。
  14. 駐車：違法駐車は絶対にしないでください。来場者・出展者向けの駐車割引はありません。

第15条禁止行為

出展者は、本会で次の行為をしてはいけません。

  1. 第5条・第6条の条件に当てはまらない作品の展示
  2. 第14条の会場規則に反する行為
  3. 割り当てられた展示スペースの外での展示・呼び込み・チラシ配り
  4. 大声での呼び込み、強引な勧誘、寄付や署名などの強要、そのほか来場者やほかの出展者への迷惑行為
  5. 机や椅子の上に乗るなどの危険な行為
  6. 本会の趣旨と関係のない作品の展示や物品の頒布
  7. 第4条3項により出展作品として認められないものの展示、および主催者の了承なく、審査を受けた作品と異なる作品に差し替えて展示すること
