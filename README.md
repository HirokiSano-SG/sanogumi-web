# 株式会社佐野組 公開サイト

GitHub Pages の静的サイトです。カスタムドメインは `CNAME` の `www.sanogumi.biz` です。この URL は電子公告の掲載先でもあります。ビルド手順はありません。

ローカル確認は同一オリジンの静的サーバで行ってください（例: `python3 -m http.server`）。`file://` では `works.json` を読めません。

## 作品を追加する

作品カードは HTML に書きません。`works.json` の `works` 配列にオブジェクトを 1 件追加してコミットします。トップの抜粋と `works.html` は同じファイルを読みます。

表示順は配列の順です。

| フィールド | 必須 | 内容 |
| --- | --- | --- |
| `id` | 推奨 | ページ内アンカー（英数字とハイフン） |
| `title` | はい | 日本語タイトル |
| `titleEn` | いいえ | 英語タイトル |
| `kind` | いいえ | ジャンル |
| `price` | いいえ | 価格表示（税表記も含めてそのまま出す） |
| `priceNote` | いいえ | 価格欄の見出し。省略時は「価格」。例: `予定価格` |
| `platforms` | いいえ | 対応プラットフォーム |
| `publisher` | いいえ | 販売元 |
| `links` | いいえ | 店舗・サイトなどの配列 |

`links` の各要素:

| フィールド | 必須 | 内容 |
| --- | --- | --- |
| `label` | はい | リンク名（例: `unityroom`, `Steam`, `作品サイト`） |
| `url` | いいえ | あるときだけリンクにする。未公開なら省略 |
| `status` | いいえ | ラベル横に「（…）」で出す。例: `coming`, `準備中` |

例:

```json
{
  "id": "new-title",
  "title": "新しい作品",
  "titleEn": "New Title",
  "kind": "ジャンル",
  "price": "980円＋税",
  "links": [
    { "label": "作品サイト", "url": "https://example.com", "status": "準備中" }
  ]
}
```

個人名のクレジットは載せません。販売元を書く場合は会社名だけにします。
