情報セキュリティ基本方針

株式会社佐野組は、ゲームの開発とパブリッシングを通じて、お客さま、お取引先、一緒に作る仲間からお預かりする情報を守ることを大切な責任と考えます。そのために、次の方針で情報セキュリティに取り組みます。

1. 経営者の責任

代表取締役が先頭に立ち、情報セキュリティに継続して取り組みます。

2. 社内の体制

情報セキュリティの担当を決め、取り組みを進める体制を整えます。情報セキュリティの対策を社内の規則として定め、これを守ります。

3. 従業員・協力者の取り組み

従業員と業務の協力者は、情報セキュリティに必要な知識と心がけを身につけ、日々の業務で実践します。私物のパソコンで業務をする場合も、この方針に沿って取り扱います。

4. 情報の取り扱い

  • 業務で使うアカウントには2段階認証をかけ、パスワードを使い回しません。
  • パソコンや業務で使うソフトウェアは、最新の状態に保ちます。
  • データの共有範囲は必要な人に限ります。
  • 生成AIなどの外部サービスを使うときは、秘密にすべき情報や個人情報の扱いに注意します。
  • 個人情報は、プライバシーポリシーに沿って取り扱います。

5. 法令と契約上の義務の遵守

情報セキュリティに関する法令、国が定める指針その他の規範、および契約上の義務を守ります。

6. 違反と事故への対応

情報セキュリティに関する法令や契約への違反、情報の漏えいなどの事故が起きたときは、速やかに原因を調べて被害を抑え、適切に対処して再発防止に努めます。必要な場合は、関係する方へお知らせします。

7. 見直し

情報セキュリティの状況を定期的に見直し、取り組みを改善していきます。

当社は、IPA（独立行政法人情報処理推進機構）が実施する SECURITY ACTION の二つ星を宣言しています。
